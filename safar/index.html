    Safar ka log

    Station aur OSM route lists APK ke saath bundled hain; internet ke bina bhi route aur station logging kaam karni chahiye. Station data purana ya galat ho sakta hai. Safar shuru hone se pehle Start dabayein; screen on aur app khula rakhein. Browser location ka source khud chunta hai; network location ki accuracy kam ho sakti hai. OSM se bana route track connectivity ka anumaan hai, aapki train ka scheduled ya live route nahi. OSM station-code matches abhi review nahi hue aur OSM network ki coverage verify nahi hai. GPS, chhute stations aur galat station data ki wajah se log galat ho sakta hai. Station chhodne ke baad log dikhega; purana safar wapas nahi milega.
